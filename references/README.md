# Design references

Open `stitches-interactive.html` in a browser to explore the design. It is self-contained apart from optional runtime/CDN resources used by the original preview wrapper; the provided screenshots preserve the appearance if those resources are unavailable.

The interaction works locally and does not call Gemini, Sanity, or a drafting service. Browser-local reference state may be restored by the preview wrapper. The development source is `stitches-reference.fragment.html`.

The desktop and dark screenshots show the final original/proposed outline treatment. The mobile and fabric screenshots capture other demo states, so their selected values may differ. The saved interaction state is interface context only, not a personal measurement profile or proof of real sewing.

Rebuild the workspace as application components. Do not use these paths, drawing formulas, or fabricated yardage estimates as production geometry. The production design should enlarge the smallest labels, support keyboard-accessible canvas actions, and give mobile sewing a focused layout.
